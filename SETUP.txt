========================================
MINING MINI-APP BOT — SETUP (Bangla)
========================================
ETA SHUDHU IN-APP POINTS BOT.
Kono real crypto na, kono real taka na, kono payment / withdraw NAI.
User shudhu app-er vitore point (token) jomabe.

----------------------------------------
1) BOT BANAN (BotFather)
----------------------------------------
- Telegram-e @BotFather khulun
- /newbot -> bot-er name din -> username din (sheshe _bot thakte hobe)
- BotFather je BOT_TOKEN dibe, ota kothao chat-e likhben NA — shudhu Render env var-e diben.

----------------------------------------
2) ADMIN_ID BER KORUN
----------------------------------------
- Telegram-e @userinfobot khulun, /start din
- Je number ID dibe (jemon: 123456789), otai ADMIN_ID.

----------------------------------------
3) GITHUB-E FILE UPLOAD
----------------------------------------
- GitHub-e notun Public repo khulun (jemon: mining-bot)
- Ei folder-er SOB file upload korun: bot.py, requirements.txt, webapp/ (index.html, app.js, style.css)

----------------------------------------
4) RENDER-E HOSTING (Free)
----------------------------------------
- render.com-e giye New + -> Web Service -> GitHub repo select korun
- Build Command:  pip install -r requirements.txt
- Start Command:  python bot.py
- Plan: Free ($0)
- Environment Variables (Render dashboard-e):
    BOT_TOKEN = (BotFather-er token)
    ADMIN_ID  = (apnar Telegram numeric ID)
    WEBAPP_URL = (Render link pawar por bosaben, niche dekhun)
- Create Web Service chap din. 2-3 minute por link paben, jemon:
    https://mining-bot-xxxx.onrender.com

----------------------------------------
5) MINI APP URL SET KORUN
----------------------------------------
- Render-er link ta copy kore abar Render env var-e jan:
    WEBAPP_URL = https://mining-bot-xxxx.onrender.com
- Tarpor Render-e Manual Deploy -> Deploy latest commit chap din.
- BotFather-e giye: /mybots -> apnar bot -> Bot Settings -> Menu Button
  -> Configure menu button -> URL-e oi Render link ta bosan.
  Ekhon bot-e /start dile "Open Miner" button asbe.

----------------------------------------
6) ADMIN PANEL (SHUDHU BOT-E)
----------------------------------------
- Telegram-e bot-e /admin likhun (shudhu ADMIN_ID parbe).
- Ekhane theke change korte parben:
  * Token name / symbol (default: MINE)
  * Free plan-e protidin koto token (default: 10)
  * Base hashrate (default: 1.00 TH/s)
  * Force-join channel username
  * Stats: total users / total mined
- Admin Panel Mini App-er vitore NAI — shudhu bot-e, shudhu admin dekhbe.

----------------------------------------
7) FORCE JOIN (optional)
----------------------------------------
- Prothome bot-ke apnar channel-er admin banan.
- Tarpor /admin -> Force-join channel -> channel username likhun (jemon: TonmoyDeveloperBD24)
- Ekhon je user channel-e join kore nai, Mini App-e "Join Channel" dekhabe.
- Bondho korte chaile 'off' likhun.

----------------------------------------
8) KIVABE KAJ KORE
----------------------------------------
- User Mini App khule "Start Mining" chap dibe, tarpor ar kichu korte hobe na.
- Token aste aste jombe (auto mining, tap-to-earn NA).
- 24 ghonta porjonto jome; tarpor cap — "Collect earnings" chap dile balance-e joma hobe.
- Miners kinle hashrate barbe, aro taratari token jombe.
- Level: mot jomano token-er upor level bare (1-100).

----------------------------------------
GURUTTOPURNO SOTORKOTA
----------------------------------------
- BOT_TOKEN kokhono chat-e, GitHub file-e ba video-te dekhabe NA.
- Render free plan-er disk-e data.json thake, kintu redeploy korle data harate pare.
  Tai majhe majhe data.json-er backup rakhun.
- Free plan-e Render 15 minute na cholle ghumiye jay; prothom open-e 20-30 second lagte pare.
